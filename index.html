Новый тренер
Без этого ссылку сможет открыть кто угодно, но НЕ увидит панель тренера — только с этим VK ID человек, открывший ссылку, будет узнан как тренер демо. Спроси VK ID у того, кому показываешь демо. Можно добавить позже.
Из ссылки на сообщество или из «Управление → Сообщения API → ID сообщества».
Чтобы тренер получал уведомления и видел свою админку. Можно добавить позже.
Необязательно — можно поменять позже. Без цвета будет тема по умолчанию.
Из «Управление → Работа с API» группы тренера, права «Сообщения сообщества» + «Управление сообществом». Без него бот не сможет отвечать в этой группе — можно добавить позже.
Таблица под тренера создастся автоматически (копия шаблона с демо-клиентами), доступ сгорит через 48 часов сам. Ссылку — из списка тренеров, кнопка «Открыть как тренер».
📅 Новая неделя

Если клиент вытянул план или больше — вес чуть подрастёт сам (+2.5кг или +5%). Если не вытянул — новым планом станет тот вес, что реально сделал. Ты всё равно сможешь поправить любое упражнение вручную после создания недели.
